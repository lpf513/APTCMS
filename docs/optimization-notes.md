# APTCMS 继续优化建议（已按当前代码可落地）

## 本轮新增完成

1. 文章服务升级为 MySQL 优先 + JSON 回退双模式。
2. 后台密码改为 `password_hash` 校验（兼容旧明文字段）。
3. AI 接口支持分页与增量同步参数（`page`、`limit`、`updated_after`）。
4. sitemap 增加 `lastmod/changefreq/priority`。
5. 模板引擎支持对象字段访问（如 `{$row.code}`）。
6. 模型字段类型覆盖完整规范（10 种字段类型）。
7. 增加 `robots.txt` 输出与 API 游标（cursor）能力。
8. 增加插件加载器（plugins/*/bootstrap.php）。
9. 后台新增模型字段详情页。
10. AI 接口增加请求频率限制与限流审计。
11. 后台增加 IP 白名单访问控制。
12. 审计日志自动滚动与归档清理。
13. 审计日志筛选（事件/IP/关键词/条数）。
14. 审计日志 CSV 导出。
15. 后台用户与 RBAC 权限支持数据库化（安装时自动初始化）。
16. 模型配置支持数据库化（apt_model/apt_model_field）。
17. 内容模块支持严格 DB 模式（可关闭 JSON 回退）。
18. 插件清单增加版本约束与依赖校验（含审计记录）。
19. 插件生命周期管理（启用/禁用/卸载/恢复）。
20. 插件远程安装/升级流程（URL zip）。
21. 系统基础配置支持数据库化（apt_system_setting）并在启动时自动合并覆盖。
22. 后台新增系统配置中心（DB 覆盖项维护），补齐 API 分页/限流、登录限流窗口、后台 IP 白名单等配置项，并记录配置变更审计（含旧值/新值差异）；支持按关键词/操作人/时间范围/条数查看最近配置变更，并支持 CSV 导出；补充近 N 条变更键名统计（Top 10）。

## 建议继续优化（下一阶段）

1. **数据库全量化（进行中）**：已完成用户/权限/模型配置/系统基础配置落 DB，并补齐后台配置中心与配置变更审计；下一步是扩展更多业务模块配置项数据库化。
2. **后台可视化建模**：字段拖拽、校验规则、模板绑定 UI。
3. **插件系统标准化**：已支持依赖声明、版本兼容校验、生命周期管理与远程安装/升级流程。
4. **AI 驱动生产化**：重试、熔断、成本监控、模型路由。
5. **SEO 自动化增强**：内链推荐、链接健康检查、自动重定向策略。
6. **GEO 增强**：知识增量游标、主题聚类、跨语言知识包。
7. **性能增强**：Redis 缓存、查询缓存、静态化发布、队列异步。
8. **安全增强**：2FA、权限最小化策略、敏感操作二次确认。
